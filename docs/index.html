ボレーシュートチャレンジ（VolleyShootChallenge）

愛称「ボレチャレ」。ボレーシュートの反応、タイミング、集中力をスマートフォンで楽しく鍛えるサッカートレーニングアプリです。

プライバシーポリシー サポート マーケティング情報

主な機能

  • カメラ映像を使ったリアルタイムのキック動作認識
  • 画面内に飛んでくるボールへの反応トレーニング
  • 成功率、スコア、コンボを使った継続しやすい練習体験
  • EASY、NORMAL、HARD の難易度設定

対象

サッカーのボレーシュート練習、反応速度の向上、親子やチームでの短時間トレーニングに利用できます。
