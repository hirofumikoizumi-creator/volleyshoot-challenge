# Models

Place on-device pose `.tflite` models here.

The app must use an on-device model only. Do not add model-loading code that downloads frames or sends camera images to a remote server.

Current primary asset:

```text
assets/models/movenet_singlepose_lightning_int8.tflite
```

Legacy experiment asset:

```text
assets/models/blazepose_lite.tflite
```
